# ☢️ Бункер 3.3 — Настольная игра (Web Edition)

Веб-версия популярной дискуссионной игры на выживание «Бункер» (Редакция 3.3) с поддержкой мультиплеера в реальном времени.

## Особенности игры
- **🎮 Игра с любых устройств:** работает в браузере на смартфонах (Safari/Chrome), планшетах и ПК без установки сторонних приложений.
- **🔍 Индивидуальное досье в 1 клик:** каждый игрок со своего экрана видит список всех выживших. Тапнув по любому игроку, можно просмотреть все его открытые характеристики или статус засекреченных карт.
- **🤫 Секретная рука:** личные 6 карт и «Особое условие» скрыты от соперников до момента вскрытия в свой ход.
- **🗳️ Тайное голосование:** цифровой анонимный бюллетень прямо на экране телефона с автоматическим подсчётом голосов и исключением по правилам редакции 3.3.
- **🎬 Кино-герои и классические колоды:** в базу добавлены карты, вдохновленные героями фильмов и сериалов (*Breaking Bad, House M.D., Dexter, The Office, The Last of Us, Iron Man, John Wick, Sherlock* и др.).
- **🔊 Звуковые эффекты:** встроенный аудио-синтезатор (пневмозатвор шлюза, сигналы тревоги, таймеры) на базе Web Audio API без внешних аудиофайлов.

## Стек технологий
- **Backend:** Python 3 (асинхронный сервер на `asyncio` и `websockets 17.2`). Единый порт для отдачи статики и WebSocket-соединений.
- **Frontend:** Чистый HTML5, Vanilla CSS (постапокалиптический терминал, адаптивная верстка, dark mode), Vanilla JavaScript.
- **База карт:** `cards.json` (10 колод: Профессии, Биология, Здоровье, Хобби, Багаж, Факты, Особые Условия, Катастрофы, Бункер, Угрозы).

## Быстрый запуск

1. Убедитесь, что установлен Python 3.10+ и библиотека `websockets`:
   ```bash
   pip install websockets
   ```
2. Запустите игровой сервер:
   ```bash
   python server.py
   ```
3. Откройте в браузере:
   - На компьютере: `http://localhost:8000`
   - С телефонов в локальной сети: `http://<IP-адрес-компьютера>:8000`
